# 心与星寻 · H5 网页版 v0.12.0（四端同源版）

uni-app 构建的 H5 产物（hash 路由 + 根路径 base）。

- 版本：v0.12.0（versionCode 1120）
- 变化：设备记录归户（claimLocal）——同一台设备先后登录不同账号，匿名期写下的记录会在登录后归属到当前账号；检测到设备上有别的账号的数据时会拒绝推送、只拉不推，避免串数据。
- 红线：不诊断、不替代测评、不给用药建议、不做 AI 咨询（输出层硬过滤）。
- 数据：与 App / 微信小程序 / Streamlit 网页版共用同一个云端账号体系（手机号或微信登录即通）。
- 模型服务在境内（腾讯混元），文字不出境。

> 部署要求：必须放在域名根目录（资源是绝对路径）；不要用 GitHub Pages 项目站点子路径。
